# 注音轉拼音大作戰 (Zhuyin to Pinyin Mastery Quest)

> 專為習慣注音符號（ㄅㄆㄇㄈ）的學習者量身打造的漢語拼音與輸入法遊戲化闖關教學平台。

---

## 📌 背景與開發初衷

在台灣，多數人自幼熟悉**注音符號**與**大千式注音鍵盤**（分佈於鍵盤 4 排按鍵，包含數字鍵與聲調鍵）。當面對跨國溝通、國際標準文檔、編程環境或行動裝置上的漢語拼音輸入法時，經常會遇到以下習慣轉換瓶頸：

1. **英文字母形狀盲區**：例如注音「ㄑ」對應拼音「q」、「ㄒ」對應「x」、「ㄘ」對應「c」，第一反應常不知所措。
2. **捲舌音與平舌音混淆**：在注音中 ㄓ/ㄗ、ㄔ/ㄘ、ㄕ/ㄙ 是不同鍵位，而在拼音中規則是「捲舌音加 h（zh/ch/sh），平舌音為單字母（z/c/s）」。
3. **拼音特殊縮寫與省略規則**：
   - `j, q, x` 遇到 `ü`，上面的兩點省略寫作 `u`（如「去」qu、「學」xue）；而 `n, l` 遇到 `ü` 必須保留兩點，鍵盤上以 `v` 代打（如「女」nv、「綠」lv）。
   - 「ㄧㄢ」讀音似 yen，但拼寫一律為 `ian`（如「天」tian）。
   - 「ㄨㄥ」接聲母一律變為 `-ong`（如「中」zhong、「東」dong），單獨成字才拼 `weng`。
   - 縮寫三人組：`ㄧㄡ` 接聲母縮寫為 `iu`、`ㄨㄟ` 縮寫為 `ui`、`ㄨㄣ` 縮寫為 `un`。
4. **打字效率認知升級**：拼音輸入法最核心的優勢是**免打聲調**以及支援**聲母簡拼**（例如輸入 `zznc` 秒出「珍珠奶茶」），能大幅解放手指移動負擔。

本專案參考 [ifreesite 漢語拼音對照表](https://www.ifreesite.com/phonetic/phonetic.htm)，結合遊戲化闖關積分機制，讓使用者在趣味挑戰中自然建立拼音肌肉記憶！

## ✨ 核心特色與功能

### 1. 15 大進階階梯闖關地圖（越後面越難！）
難度循序漸進，由單一字母過渡到複雜組合與盲打反應：
- **關卡 1**：基礎聲母啟蒙（ㄅㄆㄇㄈ · ㄉㄊㄋㄌ · ㄍㄎㄏ）
- **關卡 2**：舌尖平舌三劍客（ㄗ=z · ㄘ=c · ㄙ=s，重點防禦 ㄘ=c 盲點）
- **關卡 3**：捲舌音四重奏（ㄓ=zh · ㄔ=ch · ㄕ=sh · ㄖ=r）
- **關卡 4**：平捲舌極限瞬發對抗（ㄓ vs ㄗ、ㄔ vs ㄘ、ㄕ vs ㄙ 快速分辨）
- **關卡 5**：舌面新字母大解密（ㄐ=j · ㄑ=q · ㄒ=x）
- **關卡 6**：基礎單韻母與介母（ㄚㄛㄜㄝ · ㄧㄨㄩ，含鍵盤 v 鍵密技）
- **關卡 7**：複合韻母快速反應（ㄞ=ai · ㄟ=ei · ㄠ=ao · ㄡ=ou）
- **關卡 8**：前後鼻音分水嶺（ㄢㄣ前鼻 -n vs ㄤㄥ後鼻 -ng，辨析 ㄣ/ㄥ 及 in/ing）
- **關卡 9**：結合韻母ㄧ系與縮寫陷阱（ㄧㄚ, ㄧㄝ, ㄧㄠ, ㄧㄡ=iu, ㄧㄢ=ian）
- **關卡 10**：結合韻母ㄨ系與縮寫魔王（ㄨㄥ=ong, ㄨㄟ=ui, ㄨㄣ=un）
- **關卡 11**：結合韻母ㄩ系與 ü 兩點消失術（ju/qu/xu 脫帽 vs lv/nv 鍵盤打 v）
- **關卡 12**：台灣人高頻易錯盲區大合集（混搭 ju/qu/xu, -ian, -ong, iu, ui, un）
- **關卡 13**：台灣生活美食與地名極速拼寫（珍珠奶茶、高鐵、捷運、悠遊卡）
- **關卡 14**：成語簡拼與長句極限拼寫（四字成語聲母簡拼思維）
- **關卡 15**：拼音至尊殿堂 · 極限考核（全方位混合盲打大考驗）

> **動態隨機題目選項**：系統採用 Fisher-Yates 洗牌演算法，每一題載入時皆動態打亂選項排序，杜絕固定位置！

### 2. 真實拼音輸入法（IME）實戰模擬器
- 支援實體鍵盤敲擊與即時監聽。
- 具備真實輸入法浮動候選詞視窗（Candidate Bar）。
- 支援**全拼輸入**與**首字母簡拼輸入**（如敲擊 `tw` 出「台灣」，按空格鍵或 `1` 瞬間上屏）。
- 實時統計完成詞數、打字連擊數（Streak）與 EXP 經驗值回饋。

### 3. 注音 ⇄ 拼音 智能速查與拆解字典
- 完整收錄 21 聲母、7 單韻母與介母、4 複韻母、5 鼻音韻母、18 結合韻母及 5 種聲調。
- **智能音節剖析機**：輸入任意注音音節（如 `ㄓㄨㄥ`、`ㄑㄩ`、`ㄋㄧㄡ`），自動標示聲母、韻母、聲調，並智能高亮提醒相應縮寫或變音規則。
- 支援關鍵字即時模糊檢索與原生 Web Speech API 語音發音。

### 4. 台灣注音族專屬避坑指引（8 大魔王痛點）
- 針對 `ju/qu/xu` 脫帽、`-ian` 讀音誤區、`ㄨㄥ` 變 `-ong`、省寫三人組 `iu/ui/un`、前後鼻音區分、`v` 鍵代打 `ü` 等提供口訣與實例。
- 附帶「大千注音鍵盤（4 排鍵）」vs「QWERTY 拼音鍵盤（3 排主鍵）」的配置優勢深度對照。

### 5. 激勵體系與數據持久化
- **10 級稱號晉升體系**：注音萌新 $\to$ 聲母學徒 $\to$ 舌尖御風者 $\to$ ... $\to$ 拼音至尊。
- **10 枚專屬成就徽章**、星級累積（最高 45 顆星）、連擊加成機制。
- 所有答題數據與成就皆經由 `localStorage` 安全持久保存。
